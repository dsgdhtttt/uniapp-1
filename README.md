# uniapp开发的灵活用工系统/仿鱼泡零工平台/多城市智能招聘系统源码/全开源版

源码地址：ym7k.com/19331/

这套基于 Uniapp 开发的招聘用工平台，同时兼顾全职招聘、短期零工接单，对标鱼泡网模式，支持求职者、企业雇主双身份切换，适配多城市运营，一套源码打包搭建综合招工招聘平台，全开源可二次深度改造。

### ✅ 前端核心功能

- **双身份切换：求职者 / 雇主**
  - 求职者端：简历完善、上传简历附件、添加求职意向、工作经历；收藏岗位、投递简历、接收面试邀请、查看申请记录、沟通招工方
  - 雇主端：发布全职岗位、发布短期零工，管理接单、查看投递简历、发起面试邀约
- **首页多板块**
  - 地图找工作、全部全职职位、零工招聘、招聘会、技能培训、急招岗位、兼职岗位、红包招聘
  - 名企推荐、招聘公告信息流，支持按城市定位筛选岗位
- **零工大厅（核心特色）**
  - 按工种分类：保洁、收银、育婴员等，支持按价格、区域、性别筛选
  - 零工详情：工时、时薪、地点、工作内容、雇主信息，一键申请接单、收藏、分享
- **职位详情页**：岗位薪资、福利标签（五险一金、包住、餐补、年假等）、岗位介绍、补贴说明，支持在线沟通、投递简历
- **消息沟通模块**：求职者和雇主在线对话，面试邀请统一归集
- **个人中心**：求职意向、岗位推荐、消息中心、我的佣金、我的团队、待评价、浏览记录

### ✅ 核心能力亮点

✅ Uniapp 架构：可编译成微信小程序、APP、H5，多端分发
✅ 双业务合一：全职长期招聘 + 小时零工 / 短期活计，兼顾企业招工、临时用工
✅ 多城市运营：城市定位切换，适合区域分站、多城市招工
✅ 佣金、团队分销机制：自带推广裂变，适合劳务团队、包工头入驻
✅ 简历体系完整：支持图文 / PDF/Word 简历上传，简历进度可视化
✅ 零工接单流：雇主发活、工人抢单接单，适合建筑、保洁、家政、临时工场景
✅ 全开源版本，无加密，可自定义改 UI、新增工种、拓展变现功能（置顶、会员、招工广告）

### ✅ 适合落地场景

劳务中介公司、人力资源团队、建筑招工平台、本地零工家政平台、校园招聘、灵活用工产业园、多城市招工站点
